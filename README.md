# Desarrollo de aplicaciones móviles para Sistemas Operativos IOS Nivel Básico

## Plataforma de laboratorios

Te damos la bienvenida a la plataforma de laboratorios del curso Desarrollo de aplicaciones móviles para Sistemas Operativos IOS Nivel Básico.

Mediante prácticas incrementales, desarrollarás TaskManagerApp: comenzarás con la creación del proyecto y avanzarás hacia la construcción de interfaces, persistencia local, comunicación con servicios web, reactividad, optimización y pruebas.

## Lista de laboratorios

Cada laboratorio continúa el trabajo del capítulo anterior. Haz clic en los enlaces para consultar las instrucciones.

### Capítulo 1: Fundamentos de iOS, Kotlin Multiplataforma, Xcode y Swift

#### [Práctica incremental — Creación del Proyecto Base TaskManagerApp](Capitulo01/README.md)

- Descripción: Crear el proyecto base en Xcode, organizar su estructura y configurar el control de versiones con Git. Aplicar fundamentos de Swift para construir los primeros componentes de TaskManagerApp.
- ⏱️ Duración estimada: 216 min (3 h 36 min).

### Capítulo 2: Construcción de Interfaces (en, Kotlin Multiplataforma, Xcode y Swift)

#### [Práctica incremental — Interfaces UIKit y SwiftUI para TaskManagerApp](Capitulo02/README.md)

- Descripción: Construir interfaces con UIKit y SwiftUI, configurar restricciones de Auto Layout y establecer la navegación entre pantallas. Gestionar el estado y la comunicación entre vistas.
- ⏱️ Duración estimada: 252 min (4 h 12 min).

### Capítulo 3: Persistencia Local

#### [Práctica Incremental — Capa de Persistencia con UserDefaults, Core Data y SwiftData](Capitulo03/README.md)

- Descripción: Incorporar almacenamiento local mediante UserDefaults, Core Data y SwiftData. Guardar y recuperar información de TaskManagerApp y comprobar su conservación entre ejecuciones.
- ⏱️ Duración estimada: 288 min (4 h 48 min).

### Capítulo 4: Networking y Concurrencia

#### [Capa de Red con URLSession, Codable y Swift Concurrency](Capitulo04/README.md)

- Descripción: Implementar solicitudes de red con URLSession, procesar respuestas JSON mediante Codable y utilizar concurrencia de Swift para integrar datos remotos en la aplicación.
- ⏱️ Duración estimada: 252 min (4 h 12 min).

### Capítulo 5: Reactividad y Performance

#### [Práctica Incremental — Reactividad, Robustez y Optimización](Capitulo05/README.md)

- Descripción: Incorporar reactividad con Combine, reforzar el manejo de errores y utilizar Instruments para detectar problemas de rendimiento y aplicar mejoras en TaskManagerApp.
- ⏱️ Duración estimada: 252 min (4 h 12 min).

### Capítulo 6: Testing y Proyecto Final

#### [Práctica Incremental — Testing, UI Testing y Refactorización SOLID](Capitulo06/README.md)

- Descripción: Crear pruebas unitarias con XCTest y pruebas de interfaz con XCUITest. Refactorizar componentes aplicando principios SOLID y comprobar el funcionamiento del proyecto final.
- ⏱️ Duración estimada: 180 min (3 h).

### Capítulo 7: Evaluación final y entrega de constancia

Actividad de cierre indicada en el temario. El repositorio no contiene una guía de laboratorio independiente para este capítulo y el temario no asigna una duración específica.

## Anexo KMP

### [Retos Opcionales (KMP) por capítulo](AnexoKMP/README.md)

- Descripción: Extender los conceptos del curso mediante Kotlin Multiplatform, compartiendo modelos, interfaces, persistencia, servicios de red, lógica reactiva y pruebas entre plataformas.
- Requisitos adicionales: Android Studio con el plugin Kotlin Multiplatform, además de Xcode.
- Modalidad: Retos opcionales que no forman parte de la evaluación.
- Duración: No especificada en el anexo; no se suma al tiempo de los laboratorios principales.

El anexo incluye:

1. Saludo desde el Módulo Compartido.
2. Lista de Tareas con Compose Multiplatform.
3. Persistencia Compartida con SQLDelight.
4. Servicio de Red Compartido con Ktor.
5. Buscador Compartido con StateFlow.
6. Pruebas en commonTest.

---

Duración total de los laboratorios principales: 1440 minutos (24 horas).

Duración total del curso según el temario: 40 horas.

Distribución: 60 % de práctica y 40 % de teoría.
